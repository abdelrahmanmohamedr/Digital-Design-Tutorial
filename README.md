# ChipRun 

**Ongoing · Long-term series**

[ChipRun](#) is a slide series on digital IC design — each episode breaks down one topic end-to-end, practical and visual, so you actually learn the concept instead of just skimming it.

**This repo is the code companion to the series.** Every episode's slides walk through a concept; this is where you'll find the matching code so you can try it yourself instead of just reading along.

## How it works

- Slides teach the concept for one topic.
- This repo holds the code for that topic, organized by folder.
- Read the episode → open the matching folder → run it yourself.

There's no required order — jump into whatever's relevant to you.
